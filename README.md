📊 Excel Dashboard Portfolio – Sales, Healthcare & HR Analytics
📝 Project Overview

This project is a collection of three interactive dashboards built in Microsoft Excel, focusing on different domains: Sales, Healthcare, and Human Resources (HR). Each dashboard is designed to transform raw data into meaningful insights using visualization and interactivity.

The goal of this project is to demonstrate strong data analysis, dashboarding, and business intelligence skills using Excel.

🎯 Objectives

Analyze data from multiple domains

Create interactive dashboards for decision-making

Present insights using clear and visually appealing charts

Enable dynamic filtering using slicers

📊 Dashboards Included

🔹 1. Sales Dashboard

Analyzes business performance across regions, categories, and shipping modes.

Key Highlights:

Total Orders, Sales, Quantity, and Profit KPIs

Region-wise and state-wise sales analysis

Category and shipping mode distribution

Interactive slicers for filtering data

🔹 2. Patients Dashboard

Provides insights into healthcare data and patient demographics.

Key Highlights:

Total Patients, Doctors, and Gender Distribution

Blood group and age group analysis

Insurance provider comparison

Filters for city, alcohol consumption, and blood group

🔹 3. Employees Workforce Dashboard

Focuses on HR analytics and workforce insights.

Key Highlights:

Total, Active, and Inactive Employees

Department and country-wise distribution

Gender diversity and age segmentation

Interactive HR filters (Department, Gender, Country)
